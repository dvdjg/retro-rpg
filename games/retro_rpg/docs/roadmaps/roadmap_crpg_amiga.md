# Roadmap — CRPG Amiga

## Visión
CRPG en tiempo real, perspectiva cenital, estilo Ultima VII / Populous / SimCity, ligero para
Amiga 16 bits. Mezcla god-game y city-builder con narrativa política: estatismo, mercantilismo,
control de masas, redes clientelares, corrupción.

## Fases
1. Preproducción: decidir rol del protagonista, alcance técnico, prototipo macro-simulación.
2. Prototipo jugable: mapa cenital, facciones, infraestructuras, radio de influencia.
3. Narrativa: 3 actos, misiones, giros de guion.
4. Pulido: rendimiento en Amiga, balance y textos.

## Restricciones técnicas
- Simulación por sectores/facciones, no individuos.
- Mapas modulares y streaming de tiles.
- UI minimalista y texto denso.

## Próximos pasos
- Decidir rol del protagonista.
- Prototipo de movimiento cenital y construcción.
