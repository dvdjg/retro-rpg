# Planes Woke: Departamentos Ficticios de Coartada

## Contexto
Cuando la empresa supera el umbral de tamaño, se activa el Índice de Sostenibilidad Ideológica.
Para evitar inspecciones fiscales agresivas, se crea la Dirección de Diversidad, Inclusión y
Perspectiva de Género, contratando perfiles militantes que redactan informes inútiles.

## Objetivos
1. Crear el departamento ficticio.
2. Contratar activistas recomendados por las redes clientelares.
3. Redactar informes de "brechas salariales fantasma" y "micro-machismos".
4. Mantener el Índice de Sostenibilidad Ideológica.

## Pasos / Flujo
- Pista A: lista de activistas recomendados.
- Pista B: informes inútiles redactados.
- Pista C: subvenciones obtenidas por cumplimiento.
- Giro final: los activistas capturan puestos en la empresa.

## Consecuencias
- Si se cumple: se evitan inspecciones y se obtienen subvenciones.
- Si se incumple: se activan inspecciones fiscales agresivas.

## Notas de diseño
Los planes woke son una coartada para evitar el control fiscal.
