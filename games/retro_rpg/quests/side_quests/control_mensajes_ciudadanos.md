# Control de Mensajes entre Ciudadanos: Vigilancia Digital

## Contexto
El Estado controla los mensajes digitales entre ciudadanos con el pretexto de detectar actos
delictivos, permitiendo consultar comunicaciones privadas y dando un control tremendo sobre la
población.

## Objetivos
1. Identificar ciudadanos que critican el relato.
2. Consultar sus mensajes digitales.
3. Silenciar o criminalizar a los disidentes.
4. Mantener el relato oficial.

## Pasos / Flujo
- Pista A: lista de ciudadanos vigilados.
- Pista B: mensajes privados consultados.
- Pista C: disidentes criminalizados o silenciados.
- Giro final: el control de mensajes es una herramienta de control social.

## Consecuencias
- Si se ejecuta: se controla el relato y se silencia a la disidencia.
- Si se expone: cae la legitimidad del partido.

## Notas de diseño
El control de mensajes es una herramienta de vigilancia masiva.
Los distritos con mayor vigilancia tienen mayor lealtad pero menor libertad.
El pretexto es la detección de delitos; el control real es sobre la población.
